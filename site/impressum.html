Privacy (Datenschutz)

This website. The pages are static files. They set no cookies, store no data, run no analytics or tracking, and load nothing from third parties (no fonts, scripts or images). The only script switches the menu on small screens.

Hosting. The site is hosted on GitHub Pages. To deliver the pages, GitHub processes technical access data such as IP addresses; see the GitHub General Privacy Statement.

The product demo. The Abnahme demo runs only on Cardano preprod, a test network, with test data: test tokens and fictional people and companies. To read the fields out of free-text invoices, the converter sends the invoice text to Anthropic's Claude API. Anthropic is the processor, and its API offers no EU-only processing today. How invoice data flows is explained in the FAQ. Before any production use, data processing agreements, hosting location and retention periods still have to be settled, and a full privacy policy will be added.
