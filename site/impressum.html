Privacy (Datenschutz)

This website. The pages are static files. They set no cookies, store no data, run no scripts and no analytics or tracking. The fonts are served from this site, so the pages make no third-party requests. The site is hosted on GitHub Pages; to deliver it, GitHub processes technical access data such as your IP address; see the GitHub Privacy Statement.

Hosting. The site is hosted on GitHub Pages. To deliver the pages, GitHub processes technical access data such as IP addresses; see the GitHub General Privacy Statement.

The product demo. The Abnahme demo runs only on Cardano preprod, a test network, with test data: test tokens and fictional people and companies. To read the fields out of free-text invoices, the converter sends the invoice text to Anthropic's Claude API. Anthropic is the processor, and its API offers no EU-only processing today. How invoice data flows is explained in the project README. Before any production use, data processing agreements, hosting location and retention periods still have to be settled, and a full privacy policy will be added.
